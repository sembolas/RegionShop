User с ролями# 📋 Задачи разработки для RegionShop

Этот документ содержит пошаговый план разработки проекта RegionShop. Задачи сгруппированы по этапам и приоритетам.

## 🎯 Приоритеты задач

- **🔴 Высокий** - Базовый функционал, без которого проект не работает
- **🟡 Средний** - Важные функции, но можно работать без них временно
- **🟢 Низкий** - Улучшения, оптимизации, дополнительные функции

## 🎯 Критерии завершения этапов

### Этап 1 завершен когда:
- [ ] Запускается `docker-compose up`
- [ ] Backend доступен по http://localhost:8000
- [ ] Frontend доступен по http://localhost:3000
- [ ] База данных PostgreSQL подключена

### Этап 2-3 завершен когда:
- [ ] Регистрация пользователя через API работает
- [ ] Вход в систему и получение JWT токена работает
- [ ] Все модели созданы и мигрированы
- [ ] Django Admin доступен с тестовыми данными

### Этап 4-5 завершен когда:
- [ ] API каталога возвращает товары (пустой список - ок)
- [ ] API корзины позволяет добавлять/удалять товары
- [ ] API заказов позволяет создавать заказы
- [ ] Все эндпоинты защищены авторизацией где нужно

### Этап 6-8 завершен когда:
- [ ] React приложение показывает каталог товаров
- [ ] Можно добавить товар в корзину
- [ ] Можно зарегистрироваться и войти в систему
- [ ] Можно оформить заказ
